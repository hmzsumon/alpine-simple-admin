# Kitchen copies and category editing

Counter 1.0.37, Local Server 1.1.17 and Waiter 1.0.21-simple (22).

Menu & categories → Kitchen copy items lets Admin choose items for one Bengali preparation copy alongside the customer bill. New confirmed orders snapshot this selection. Dine-in, Parcel and Foodpanda use their responsible counter; existing print claims prevent duplicate automatic copies. Kitchen totals include selected items at their saved prices. Separate parcel token and tea-only documents are retired. Historical orders keep their saved contents.

Foodpanda entry no longer asks for an external reference. Repeated legacy reference text no longer creates a duplicate-reference review. Exact request replay, role checks, bill-change reviews and monetary protections remain. Older Counter fingerprints are accepted only when their sole difference is the new kitchen printing metadata.

Category Edit opens a dedicated item page. Select items to transfer to another category or remove to Uncategorized. Menu items, IDs, prices, kitchen settings and historical bill snapshots are retained. Uncategorized items has a dedicated Admin entry. Category rename remains available on the editor page.

Update Local Server and Counter; update Waiter to remove its reference field. Existing Owner/Admin desktop shell loads the new pages from its selected workspace. Installers are archived by version under D:\alppine-restrent\Installers.

Settings → Print queue → Clear print queue cancels waiting and uncertain local copies with confirmation. Cancellation retains the print records to prevent automatic replay after syncing/restarting, and does not change orders, payments, outbox transactions or drafts. A document already sent to the Windows spooler may finish.
