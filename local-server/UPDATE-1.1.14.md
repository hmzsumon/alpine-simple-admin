Alpine Local Server 1.1.14

Distinct teal server icon for the installer, application window and notification tray. The bundled Admin panel includes a persistent collapse/expand sidebar and category rename for users with menu-management permission. Rename updates current menu items while preserving historical bills.

The API runtime includes the existing mirror synchronization fix. Server identity, database paths, credentials and backup contracts are unchanged. Startup/recovery tests passed. Update the installed server during the normal installer restart; this release does not promise uninterrupted waiter/server traffic during that restart.
