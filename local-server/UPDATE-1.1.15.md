# Alpine Local Server 1.1.15

- Menu → Manage categories shows a labelled Edit button immediately beside each category's Delete button.
- Sidebar includes a visible Collapse sidebar control beneath the logo. When collapsed, its arrow expands the sidebar again; the top-bar control also remains available. The saved preference survives reloads.
- Category rename updates the category definition and its current menu items together, retaining historical bill snapshots and existing menu-management permissions.
- This installer includes the updated local Admin pages used by the Owner/Admin desktop app in Restaurant server mode. Updating the desktop launcher alone cannot replace Admin pages bundled in an older Local Server.
- Counter, Waiter, printing and saved restaurant data use the existing implementations.
