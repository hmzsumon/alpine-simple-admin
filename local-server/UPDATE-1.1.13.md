# Local Server 1.1.13 — second-PC creation discounts

Use Counter **1.0.32**. The second PC receives a signed creation-discount capability for cashiers already allowed to collect payments. It can save a discount before the first customer copy while payment, cash drawer and collection stay on the main PC. The server validates the original signed order, discount limits and cashier access, and accepts an exact retry only once.

Existing prepared second-PC offline orders, exclusive hall printing and review isolation are preserved. Download while the server runs, use Stop and exit for the short installation, reopen it under the existing Windows account, then sync both PCs. Keep AppData; no database reset is needed.
