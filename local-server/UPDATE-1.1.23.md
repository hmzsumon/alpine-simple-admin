Adds the Supervisor / Tablet staff role, tablet bill intake and durable customer-copy routing to the responsible main or second Counter PC. Supervisor accounts can place discounted bills for an eligible waiter and request printing, but server authentication strips cash, collection, refund, deletion and staff-management permissions from this mode. Existing accounts are not changed automatically.

Admin Staff & permissions can assign Supervisor / Tablet. The existing Management desktop app receives the updated Admin UI from this server or Cloud workspace. Requires Waiter 1.0.24-simple and Counter 1.0.44 for explicit tablet bill delivery. Foodpanda remains manually printed. Normal Counter payments, Waiter orders, station kitchen slips, offline work and quiet background sync remain supported.
