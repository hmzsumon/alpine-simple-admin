# Local Server 1.1.10 — isolated desktop sync reviews

Install with Counter 1.0.29. The server records supported bill conflicts as durable workspace review records in the same compare-and-swap commit as the device sequence. Independent sales continue to sync; rejected money is never included in accepted restaurant totals. Exact retries return the original review receipt.

Admin → Counter setup → Sync reviews supports reasoned dismissal or Foodpanda bill restoration with a unique reference. Only Admin and Owner can resolve reviews. Restoration requires the original open cash day and does not collect payments. Current and archived Foodpanda references are checked before new Counter entries are saved. Existing legacy desktop push requests retain their old protocol unless the client opts into isolation.

No production database migration, history reset or menu/staff change is required. Keep the existing server profile. Finish current saves, use **Stop and exit**, install the new version with the same Windows account, and reopen Alpine Local Server. Then update the Counter apps. Primary Counter offline operation remains available during a valid session; secondary PCs require the server.

Whole-number order quantities no longer stop at 99. Primary and secondary counter creation, revisions and waiter drafts accept 100, 500, 1000 and larger values. Invalid, fractional or unrepresentable quantities and inaccurate money totals are rejected before saving. Existing item-count, price and payment permissions remain unchanged.

Previously verified cashiers on the same primary PC can now sign in offline to its saved open drawer. While the server is connected, use Switch cashier and sign in each cashier once after this update. Passwords are not stored in plaintext: Windows protects salted scrypt verifiers and signed, device/restaurant/epoch-scoped cashier access. Offline sign-in remains bounded by the saved primary counter session and cached access expiry. Server-side permissions are rechecked on sync. Bills and payments retain the acting cashier; drawer custody remains with its responsible cashier, who must perform cash-day/custody changes. Switch cashier retains local sales and drafts. New PCs, unverified cashiers, released counters or expired sessions require the server. A changed cashier proof is held for Admin review while the responsible cashier can resume.
