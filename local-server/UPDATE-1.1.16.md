# Alpine Local Server 1.1.16

- Categories & items replaces text search with a native category dropdown, including all current menu categories and historical report categories. All categories restores the complete view; categories without sales show an empty state.
- Sales reports use the active workspace palette for readable text, tabs, counts and controls in the light desktop theme and dark web theme.
- Date, hall and employee controls share a consistent height with aligned Apply / Reset buttons, including smaller screens.
- Category selection filters the on-screen category view. Financial calculations, report-period totals and exports retain their existing scope.
- Updated Admin pages are bundled for Restaurant server mode; no Counter, Waiter, database or printing changes.
