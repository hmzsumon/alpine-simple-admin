# Counter 1.0.32 — second-PC order discounts and clearer bill totals

An authorized cashier can enter a BDT discount on the second PC's New order form before pressing F5. Saved drafts retain it. The first customer bill shows the discount and net payable; collection stays on the main PC and deducts the saved discount once. Prepared offline orders retain the discount when the server reconnects.

The net amount on customer bills is larger and bold in both graphic/Windows printing and raw ESC/POS printing. Existing F5 auto-print and exclusive waiter printing per hall are unchanged.

Install Local Server **1.1.13**, then Counter **1.0.32** on both PCs, and connect/sync once. Keep the existing Windows user and saved app data; no reset is required.
